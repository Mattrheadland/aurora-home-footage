# Aurora Home footage

Looped, colour-graded 1080p harbor clips for **Aurora Home**, a custom home screen for a Samsung Frame TV.
The TV app downloads `manifest.json` and the files in `scenes/` once and plays them from local storage.

- 1920x1080, 30 fps, H.264 High 4.1, GOP 60, ~9 Mbps, seamless loops.
- Source clips are from [Pexels](https://www.pexels.com/license/) (free to use and modify). Originals and creators are listed in `LICENSES.md`.
- These are modified versions made for a personal app. Please use the Pexels originals if you want the footage.
